This project focuses on building a Decision Tree classifier to predict whether a customer will purchase a product or service based on their demographic and behavioral data. The study uses the Bank Marketing dataset from the UCI Machine Learning Repository, which contains customer information such as age, job, education, marital status, contact type, and previous campaign interactions. The data is first preprocessed by handling missing values, encoding categorical variables, and normalizing relevant features. A Decision Tree model is then trained to learn patterns and decision rules that influence customer purchase behavior. The model’s performance is evaluated using metrics such as accuracy, precision, recall, and confusion matrix. The results help identify key factors affecting customer decisions and support data-driven strategies for targeted marketing and improved campaign effectiveness.
